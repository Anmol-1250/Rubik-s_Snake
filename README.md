# Rubik Snake 3D

A 3D Snake game played on the surface of a 4x4 Rubik's Cube.

## Features
- 3D gameplay on a rotating cube.
- Smooth camera transitions between faces.
- Increasing difficulty.
- Responsive design.

## How to Play
1. Open `index.html` in a modern web browser.
2. Use **Arrow Keys** or **WASD** to control the snake.
3. Press **Space** to reset the camera to the current face.
4. Eat the glowing purple orbs to grow and score points.
5. Avoid hitting your own body!

## Controls
- **Up/W**: Turn Up
- **Down/S**: Turn Down
- **Left/A**: Turn Left
- **Right/D**: Turn Right
- **Space**: Reset Camera

## Technical Details
- Built with **Three.js**.
- Modular ES6 JavaScript.
- CSS for HUD and menus.
